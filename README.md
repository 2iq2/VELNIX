# VELNIX

Premium bilingual live-entertainment platform.

## Current foundation
- Responsive Arabic and English landing page
- RTL / LTR language switching
- Channel category filters
- Premium dark visual identity
- Account-entry preview (authentication is not connected yet)
- Web app manifest and service-worker shell cache

## Planned development
1. Supabase authentication and member profiles
2. Channel catalogue and administration
3. Authorized live-stream sources and private-origin ingest
4. HLS playback with server-side access control
5. Favorites, electronic program guide and viewing history

Only streams VELNIX is authorized to distribute should be published.
